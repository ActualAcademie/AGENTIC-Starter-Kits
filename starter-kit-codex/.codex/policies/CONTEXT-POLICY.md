# Politique de contexte

Charger d'abord le work item, le profil projet, les fichiers directement concernés et la documentation liée. Ajouter du contexte seulement lorsqu'une preuve montre qu'il est nécessaire.

Ne pas charger automatiquement les dépendances, l'historique entier, les journaux volumineux ou les fichiers contenant des secrets. Résumer les résultats intermédiaires dans le work item plutôt que de répéter des blocs complets.

Pour chaque délégation, indiquer le but, les fichiers autorisés, les critères, le budget, la règle d'arrêt et le format de rapport.
