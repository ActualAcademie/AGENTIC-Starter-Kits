# Conception du jeu

Ce dossier complète la conception générale avec les éléments propres à un jeu.
Il reste local au projet lorsque `docs/` est ignoré.

## Documents

- `scenario.md` : fiction, objectif et limites de la partie ;
- `evidence-and-puzzles.md` : indices, dépendances et fausses pistes ;
- `student-experience.md` : parcours, règles et livrable du joueur ;
- `facilitator-guide.md` : solution, débrief et critères de correction ;
- `playtest-plan.md` : test en conditions réelles et mesures de difficulté.
