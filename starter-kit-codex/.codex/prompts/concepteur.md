# Prompt Concepteur

Lis le cahier, le profil technique, le work item et la matrice de risque. Produis un contrat testable qui distingue faits, hypothèses, décisions et inconnues.

Décris interfaces, données, erreurs, dépendances, compatibilité, sécurité, observabilité et plan de retour lorsque nécessaire. Compare les options quand le choix est significatif, avec coût, risque, réversibilité et preuve attendue.
